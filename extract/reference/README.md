# extract/reference/

Read-only reference dumps of the upstream DeepSeek Harness web-client bundles, copied out of the
installed DSH build's `app.asar` and kept **for maintainers only**. Nothing in the pipeline reads
them.

- **Not regenerated by `tools/`.** `extract-dicts.mjs` and `extract-meta.mjs` re-read `app.asar`
  directly and write only their own outputs; no script generates, validates, or diffs this folder.
  To refresh, re-copy the archive paths below out of a newer `app.asar`.
- **Never edited.** Treat each file as a frozen snapshot of the upstream bundle at reference
  version **DSH 0.2.1-rc.2** (the `version` field in both `package.json` dumps).
- The `.txt` duplicates of the same bundles — `locale-client.txt` (the same bundle with a `SIZE=…`
  header line) and `module-loader.txt` (a truncated copy of `client-modules-client.js`) — were
  deleted in the reorganization that created this folder; the table lists the surviving copies.

## Contents

Upstream paths are relative to the `app.asar` root.

| File | Upstream path (under `dsh/node_modules/@deepseek-ai/`) | Bytes | What it shows |
|---|---|---:|---|
| `locale-client.js` | `dsh-client-locale/lib/client.js` | 62951 | The locale plugin's browser bundle (`@deepseek-ai/dsh-client-locale`): the `window.__ModuleLoader__.load` registration that ships the locale service, built-in dictionaries and the language selector UI into the web GUI — the code the `vi` pack plugs into. |
| `client-modules-client.js` | `dsh-client-modules/lib/client.js` | 46292 | The browser half of the plugin client-module system: parses `window.__DSH_BOOT__`, walks the boot graph, and loads plugin bundles lazily. |
| `client-modules-host.js` | `dsh-client-modules/lib/index.js` | 42376 | The Host half of the same package: scans enabled `dsh.client` declarations, composes the boot graph and serves plugin bundles over `/plugins`. |
| `client-modules-README.md` | `dsh-client-modules/README.md` | 17324 | The upstream package reference (English section) describing the client-module system above. |
| `chat-package.json` | `dsh-client-ui-chat/package.json` | 3768 | `package.json` of `@deepseek-ai/dsh-client-ui-chat` (chat/conversation client package): exports, dependencies. |
| `locale-package.json` | `dsh-client-locale/package.json` | 2008 | `package.json` of `@deepseek-ai/dsh-client-locale` (locale plugin): entry points and dependencies. |

## Provenance

Copied out of the installed `app.asar` (the default Windows/macOS install, or whatever `DSH_APP_ASAR`
points at; reference version DSH `0.2.1-rc.2`).

All six files are byte-for-byte copies of the currently installed 0.2.1-rc.2 build, re-verified
against that archive on 2026-10-21. They are snapshots, not a live view: after a DSH update, re-copy
the archive paths above before trusting them.
